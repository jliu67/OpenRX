scientific review with no blockers. It completes 16,384 protocol-derived items,
131,072 observed private program admissions, 60 new unit tests, one complete real

## Remaining boundary

Full default hardware-dataset hashing, autonomous cache/program/table preparation,
physical bank/controller/memory service, full-capacity/whole-hash mapping, physical
PPA and architecture selection remain unresolved. The known cache0 item model
suggests 874,905,600 session clocks for a default workload; combining retained
baseline deltas gives a conditional 915,887,592-clock scenario. Retained simulator
scenarios suggest about 15.22 hours in Verilator or 5.68 days in VVP; different
work/preparation/transport may change them. These are estimates, not a measured
full hash or runtime bound. A long run requires its own reviewed admission plan.
Draft publication-head review and hosted checks remain separate merge gates;
parent owns normal merge. No physical ASIC or 1 MH/s below 2,500 W claim follows.
