## Primary-source checks

The following immutable source locations were separately retrieved and
inspected during review. This is source evidence, not execution evidence.

- [gem5 SE syscall table](https://github.com/gem5/gem5/blob/c8222cc67a399bfc01e8658dd14b30d5bfd634f9/src/arch/riscv/linux/se_workload.cc): ignored guest signal APIs, absent syscall 259 and ignored `mprotect`.
- [gem5 RISC-V faults](https://github.com/gem5/gem5/blob/c8222cc67a399bfc01e8658dd14b30d5bfd634f9/src/arch/riscv/faults.cc): unsupported instruction faults panic in SE. This conflicts with RandomX's global `Cpu` constructor's SIGILL recovery around `cpu_rv64.S` probes before `main`, even for an interpreter-only workload.
- [QEMU RISC-V Linux-user loop](https://github.com/qemu/qemu/blob/4fc49f46dc95d4a27de2509e7fceb2931e91faeb/linux-user/riscv/cpu_loop.c): flush-icache syscall succeeds because QEMU detects self-modifying code. This establishes intended emulator behavior, not a physical core's instruction-cache contract.
- [Chipyard BOOM configurations](https://github.com/ucb-bar/chipyard/blob/0acc1e1de2d3284bcd4d876956932a013ffe1949/generators/chipyard/src/main/scala/config/BoomConfigs.scala) and [BOOM V3 fragments](https://github.com/riscv-boom/riscv-boom/blob/5223e44cfeb26f41380057a2eb4d651197475f69/src/main/scala/v3/common/config-mixins.scala): V3 baseline, Medium configuration, two-wide decode, 64 ROB entries and enabled divide/square root.
- [CVA6 selected configuration](https://github.com/openhwfoundation/cva6/blob/2ef1c1b1fca419354920c5487293bc605294904e/core/include/cv64a6_imafdc_sv39_config_pkg.sv): F/D, RVV disabled, ZKN field, cache sizes and 1 GiB cached/executable DDR region. ZKN being set does not prove an implemented AES decoder/backend.
- [CVFPU operations](https://github.com/openhwfoundation/cvfpu/blob/3116391bf66660f806b45e212b9949c528b4e270/README.md): documented divide/sqrt compliance caveat and supported rounding modes.
- Root licenses at the report pins were checked for [Chipyard](https://github.com/ucb-bar/chipyard/blob/0acc1e1de2d3284bcd4d876956932a013ffe1949/LICENSE), [BOOM](https://github.com/riscv-boom/riscv-boom/blob/5223e44cfeb26f41380057a2eb4d651197475f69/LICENSE), [gem5](https://github.com/gem5/gem5/blob/c8222cc67a399bfc01e8658dd14b30d5bfd634f9/LICENSE) and [CVA6](https://github.com/openhwfoundation/cva6/blob/2ef1c1b1fca419354920c5487293bc605294904e/LICENSE). The first three use three-clause BSD terms; CVA6's root says Solderpad 0.51, while its selected config header separately identifies `Apache-2.0 WITH SHL-2.0`. This limited check does not replace a per-file/dependency redistribution inventory.
- [GCC 14 release notes](https://gcc.gnu.org/gcc-14/changes.html) and [Ubuntu Noble GCC 14 package inventory](https://packages.ubuntu.com/en/gcc-14-riscv64-linux-gnu): compiler vector-crypto support and availability of the cross package. Exact package/assembler compatibility still needs the recorded CI build.

## Reviewer-executed verification

Environment: Python 3.12.14 on the shared Linux x86-64 development workspace.
The root session generated `local-native.jsonl`; this reviewer parsed that
saved stream and exercised the validator. This reviewer did not rerun native
hashing or execute a RISC-V binary.

The exact-rational oracle check used Python `fractions.Fraction` and binary64
neighbors decoded through `struct`. No random seed or external input is used:

```python
from fractions import Fraction
import struct
def f(bits):
    return Fraction.from_float(struct.unpack('>d', bytes.fromhex(bits))[0])
one, half = Fraction(1), Fraction(1, 2**53)
assert one + half == (f('3ff0000000000000') + f('3ff0000000000001')) / 2
assert -one - half == (f('bff0000000000000') + f('bff0000000000001')) / 2
exact_mul = (one + Fraction(1, 2**52)) ** 2
lo, hi = f('3ff0000000000002'), f('3ff0000000000003')
assert lo < exact_mul < (lo + hi) / 2
lo, hi = f('3fb9999999999999'), f('3fb999999999999a')
assert (lo + hi) / 2 < Fraction(1, 10) < hi
lo, hi = f('3ff6a09e667f3bcc'), f('3ff6a09e667f3bcd')
assert lo**2 < 2 < hi**2 and ((lo + hi) / 2)**2 < 2
```

Result: all assertions passed. Multiplication rounds to the lower neighbor
except upward; division and square root round to the upper neighbor for
nearest/upward. Signed half-way add/subtract results match all four modes.

A direct mutation check accepted the saved native stream (39 required

The reviewer independently parsed both saved CI streams using the revised
validator, checked reports/empty stderr, compared the retained QEMU JSONL
byte-for-byte with its extracted counterpart, and checked the RISC-V ELF
identity and SHA-256 against its report. The exact checks executed were:

```python
from pathlib import Path
import importlib.util, json, hashlib
spec = importlib.util.spec_from_file_location('probe', 'tests/native_riscv_probe.py')
probe = importlib.util.module_from_spec(spec)
spec.loader.exec_module(probe)
base = Path('build/m3-ci-initial')
for kind in ('native', 'qemu'):
    directory = base / 'riscv-validation' / kind
    outcome = probe.validate_output((directory / 'probe.jsonl').read_text(),
                                    expect_riscv=(kind == 'qemu'))
    report = json.loads((directory / 'report.json').read_text())
    assert report['returncode'] == 0 and report['status'] == 'pass'
    assert outcome == report['validated']
    assert (directory / 'stderr.log').stat().st_size == 0
elf = (base / 'probe-riscv' / 'openrx-riscv-probe').read_bytes()
report = json.loads((base / 'riscv-validation' / 'qemu' / 'report.json').read_text())
assert elf[:6] == b'\x7fELF\x02\x01'
assert int.from_bytes(elf[18:20], 'little') == 243
assert hashlib.sha256(elf).hexdigest() == report['binary_sha256']
assert Path('docs/validation/m3/ci-qemu-initial.jsonl').read_bytes() == \
       (base / 'riscv-validation' / 'qemu' / 'probe.jsonl').read_bytes()
```

Result: native and QEMU each passed all 39 required checks, eight software-AES
hash cases, one explicitly unrequested hardware-AES skip; no assertion failed.

`61cf489ab2277477a1b5464035c21fa43c6b5e59153fe37313dbbd4ae6b4e657`.
