Source-reviewed future clean-build recipe; not executed and not applied to current canonical build.

scons defconfig build/RISCV_CLASSIC build_opts/RISCV
scons setconfig build/RISCV_CLASSIC RUBY=n USE_SYSTEMC=n USE_KVM=n
scons build/RISCV_CLASSIC/gem5.opt -j6 --without-tcmalloc

The pinned source supports these settings through src/{mem/ruby,systemc,cpu/kvm}/Kconfig and SConscript gates.
AtomicSimpleCPU, TimingSimpleCPU, Minor and O3 are gated by BUILD_ISA. There is no supported individual Atomic-only CPU model switch in this pin.
Do not promise incremental reuse if changing the existing RISCV config: SystemC contributes global CPPPATH that is also copied into helper compilation; Ruby contributes NUMBER_BITS_PER_SET to global CPPDEFINES. SCons correctly invalidates affected action signatures and rebuilds ordinary objects.
Runtime FS acceptance still requires exact effective config provenance and actual boot/hash evidence, independent of successful compilation.
