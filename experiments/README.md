# Experiments

Copy TEMPLATE.md to a numbered experiment. Track hypothesis → configuration → correctness → measurements → interpretation → next action. Negative and failed results belong in the record. Use GitHub research/experiment issue templates for ownership and discussion; durable conclusions go into memory and docs.

Resource-intensive experiments are held by [migration #27](https://github.com/jliu67/OpenRX/issues/27),
currently **STAGING; NOT YET ACTIVE**. After verified cutover they use the designated Ubuntu host and
[local execution request/evidence interface](../docs/LOCAL_EXECUTION.md).
Remote execution/retrieval is unavailable; owner-mediated GitHub submission/result publication is required.
Every attempt retains a fresh execution ID, source/input/configuration digests, exact commands/logs and scientific oracle.
Do not infer completed validation, scientific checkpoint resume or access from a process launch or issue claim.
